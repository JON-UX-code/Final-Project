# Stream.Node Chat Application

## Project Description
Stream.Node is a JavaFX chat application that allows multiple users to connect to a server and send messages in real time using socket programming. Users enter a username, join the chat room, and communicate through a gui.

## Implemented Features
- Username login screen
- JavaFX graphical user interface
- Client-server communication using sockets
- Multiple clients connected at the same time
- Real-time message broadcasting
- Message timestamps
- Disconnect button to leave the chat
- Exit button to close the application
- JUnit test cases
- Maven project structure
